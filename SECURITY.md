# Security

Please do not disclose exploitable details in a public issue. A private reporting channel has not yet been designated: selecting and publishing one is an owner decision. Until then, avoid posting sensitive details publicly; no response or support window is promised.

Security-sensitive changes, especially enrollment, authorization, recovery and credential storage, require independent security review and evidence of negative-path testing before production use. Do not include secrets or personal data in reports, fixtures or logs. Coordinate disclosure and remediation timing with maintainers once a private channel exists. The current designs are proposals, not validated security guarantees.
