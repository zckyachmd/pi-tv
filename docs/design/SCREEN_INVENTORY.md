# Screen inventory

Proposed for review; IDs identify screen groups, not separate pages for each state. [PRD](../../PRD.md) requirement IDs are authoritative; component names refer to the [catalog](COMPONENT_CATALOG.md). State terms refer to the [state model](UI_STATE_MODEL.md). All screens provide accessible names, roles and state, readable errors, non-color cues and localized reflow (R-19). TV uses visible focus and safe margins; iOS uses safe areas, system type, Dynamic Type, VoiceOver and 44 pt targets. No screen exposes credentials or assumes trust from proximity, radio or focus. Phone-based enrollment and recovery ceremonies remain subject to security approval; see [recovery](../architecture/RECOVERY.md).
