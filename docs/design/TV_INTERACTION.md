# TV interaction

Proposed. Design on a 1920×1080 reference canvas with 5% safe inset: 96 px horizontal, 54 px vertical. At 1280×720 use 64 px and 36 px; reflow and verify actual legibility rather than assuming proportional screenshots are usable. Allow overscan adjustment only if later supported by measured need. Background may fill the screen; controls and focus outlines stay inside the safe area. Start with three equal columns and 24 px gutters at 1080p, adapt count to available width and content; use a 4/8 px spacing rhythm. Title 48, section 32, body 24, metadata 20 px at reference size; test at distance on both resolutions.

One focused item has a solid 4 px outline at 1080p, contrasting at least 3:1 against adjacent pixels; keep it visible and distinct from selection and transient press. At 720p preserve at least 3 px. Do not rely on glow, animation or color alone.

Arrow navigation is geometric, never the prototype's linear next/previous behavior. Filter enabled, visible candidates whose center is in the requested half-plane; prefer candidates overlapping the source on the perpendicular axis, then smallest forward edge distance, perpendicular center distance, and stable visual order as tie-breaker. For grids, preserve column intent when changing rows and choose nearest available item in a short row. No wrapping unless a specific control declares it. If none exists, stay and provide no false activation; ensure every actionable group is reachable. Skip disabled items, but expose their reason in adjacent readable text. Focus remains within the visible scroll region and scrolls into view.

A modal traps focus, initially on the least destructive relevant action; Back cancels when safe. On close restore the invoking control, or nearest enabled sibling, then page heading if none. Returning Home restores the last still-available tile; otherwise first enabled tile, then a focusable empty-state action. When text input owns focus, arrows, selection and editing keys remain with the input unless an explicit escape or exit action releases it; asynchronous updates never steal focus.

Loading shows a static message and cancel where possible; empty gives a next step; offline distinguishes local control from provider connectivity; errors explain recovery without claiming success. Pairing, recovery and confirmation are subject to the reviewed phone-based authorization policy, never focus alone. Authenticated iPhone remote acceptance covers every direction, grid edges, disabled entries, modal trap/restore, Home restoration, typing and all recovery paths.
